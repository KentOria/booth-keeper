Support

Questions, bug reports and feature requests are welcome. Please write to:

oria.tokyo@gmail.com

If you report a bug, please include your iPhone model, iOS version, and what you saw on screen.

The timer did not start

The timer starts by itself at the start time you entered. There is no start button. Check that the start time and date are correct. An end time earlier than the start time is treated as the next day.

The alerts make no sound

This is intentional. DJ Buddy never plays sound, so it cannot interrupt the music in the booth. Alerts 10 minutes and 3 minutes before your set use vibration only. Please allow notifications for DJ Buddy in the Settings app.

Where is my guest list saved?

Only on your iPhone. It is not sent anywhere. If you delete the app, the guest list is deleted too. Use Send list to keep a copy outside the app.

不具合のご報告には、iPhone の機種、iOS のバージョン、画面に何が出たかを添えていただけると助かります。

タイマーが始まらない

タイマーは、入力した開始時刻になると自動で始まります。開始ボタンはありません。開始時刻と日付が合っているか確認してください。終了時刻が開始時刻より前のときは、翌日として扱います。

お知らせの音が鳴らない

仕様です。ブースの音を邪魔しないよう、DJ Buddy は音を一切鳴らしません。出番の10分前と3分前のお知らせは、バイブだけで届きます。設定アプリで、DJ Buddy の通知を許可してください。

ゲストリストはどこに保存されますか

お使いの iPhone の中だけです。外部には送信しません。アプリを削除すると、ゲストリストも消えます。控えを残すときは「Send list」で書き出してください。
